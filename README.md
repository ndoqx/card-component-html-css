Stats Preview Card Component
This is a frontend practice project based on the Frontend Mentor Challenge. I used HTML and CSS to build a responsive card component that displays business stats with an appealing visual layout.

Project Goals
•	Practice writing clean HTML and CSS
•	Use Google Fonts and custom variables
•	Learn how to structure a responsive layout using Flexbox
•	Understand mix-blend-mode and how image overlay effects work
•	Improve mobile responsiveness with media queries

Technologies Used
•	HTML5
•	CSS3
•	Google Fonts
•	Responsive Design (Media Queries)
•	Visual styling with mix-blend-mode
 
What I Learned
•	How to structure a component with two sides (text + image)
•	Using Flexbox for layout and alignment
•	Applying semi-transparent overlays to images
•	Creating mobile-first responsive design
•	Managing CSS variables for cleaner styling

How to Run It
1.	Clone or download the project:
2.	git clone https://github.com/your-username/stats-preview-card.git
3.	Open index.html in your browser.
